# ai-prompts

面向 AI 大模型的高质量提示词集合。每条提示词都是一份完整、可验收的任务书，而不是风格描述式的泛泛要求。

## 收录

| 文件 | 说明 |
|---|---|
| [`bot-video-prompt.md`](bot-video-prompt.md) | 30 秒 motion graphics 视频制作任务书（英文原版） |
| [`bot-video-prompt-zh.md`](bot-video-prompt-zh.md) | 同一份任务书的中文版 |

## 怎么用

把文件全文作为提示词交给模型。执行方需要具备联网调研、写代码、运行命令和自行检查产物的能力，因此在 Claude Code、Codex 这类 agent 环境中效果最好。

在 Claude Code 中可以直接引用：

```
@ai-prompts/bot-video-prompt-zh.md 按这个提示词执行
```

或把文件内容整段粘贴到任意对话模型里。

## 中英两版的关系

`-zh` 是英文原版的逐句中文对照，不做增删。屏幕上的英文文案（如 `Meet ◉ Grok Bot`）保留原文并附中文释义，避免执行时把画面文字替换掉。

修改其中一版时，请同步另一版，保持语义一致。

## 不适用

- 不是可直接运行的视频生成工具，仓库里没有模型、脚本或渲染器
- 不保证成片达到专业作品集水准：提示词给出的是流程与约束，结果取决于执行模型和迭代次数
- 涉及第三方产品（如 xAI 的 Grok Bot）的提示词只是创作任务描述，与本仓库无隶属或授权关系
